Overview & Billing Behavior

The Reseller API lets you connect your website, app, or business tools directly to Wener Developer so workflows execute automatically—ordering virtual numbers, placing SMM orders, buying marketplace goods, or provisioning client sites—billed straight from your wallet at standard user rates with zero extra API markup.

  • • Every successful call debits your wallet balance immediately.
  • • Failed calls (422, out of stock, invalid input) are never charged.
  • • Every API order is logged cleanly in your transaction history.
  • • No artificial rate limits beyond your available wallet balance.

Getting an API Key & Authentication

  1. Connect via WhatsApp to activate your Developer Portal.
  2. Request a Production or Staging X-API-Key label.
  3. Fund your wallet balance to authorize billable API calls.
